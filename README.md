# Focus / Tabindex 測試頁

比較「原生 `<button>`」與「`<div>` 模擬按鈕」在鍵盤操作（Tab / Enter / 空白鍵）上的行為差異，用來示範無障礙（a11y）鍵盤操作的重要性。

## 使用方式

直接用瀏覽器開啟 [index.html](index.html) 即可，或搭配任一靜態伺服器：

```bash
npx serve .
```

## 測試步驟

1. 用滑鼠點一下網址列或頁面空白處，讓焦點離開所有按鈕
2. 按 `Tab` 鍵，觀察焦點是否依序移到每一顆按鈕上
3. 焦點停在按鈕上時，分別按 `Enter` 和 `空白鍵`，觀察畫面訊息是否有反應
